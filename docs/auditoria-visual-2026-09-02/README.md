## Escopo e observações

- Foram cobertas as telas de usuário navegáveis: hubs, painéis, listas, estados vazios/filtrados, criação, edição, detalhes, estados de fluxo, confirmação de exclusão e casos responsivos.
- Os formulários demonstrativos foram preenchidos apenas no navegador e não foram enviados. Nenhum registro de negócio foi criado ou alterado.
- Rotas de exportação, APIs, ações POST sem tela própria, parciais internas, e-mails e o Django Admin não entram no acervo de telas do produto.
- O detalhe de roteiro redireciona para o mesmo editor; portanto, há uma única captura por estado visual, sem duplicar a mesma tela.
