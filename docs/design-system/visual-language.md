# Linguagem visual

**Hoje**: identidade PCPR — grafite (`--n-900 #333`) na faixa de identidade, dourado institucional (`--d-500 #bea45a`)
como acento, neutros quentes, fundo papel (`#fafafa`), controles com contorno arredondado, tabela em painel,
indicadores com ícone (Lucide, traço 1,8). Tipografia Segoe UI/system-ui. Sem tema escuro.
Ajustes por atributo: `html[data-densidade]`, `html[data-dourado]`, `html[data-divisorias]`.

**Avaliação**: identidade forte e coerente com a instituição. Problemas: o dourado de acento tem 2,33:1 sobre papel
(não serve para texto nem ícone informativo); três gerações de CSS convivem; hierarquia tipográfica feita com 115 tamanhos.

**Regra v4**: manter grafite + dourado + neutros quentes; dourado **escuro** (`gold.700 #7d6626`, 5,29:1 sobre papel) para texto/links;
dourado claro só como superfície/realce. Tema escuro fica fora do escopo até haver demanda.
