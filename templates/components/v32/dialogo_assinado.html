{% load estaticos %}{% comment %} Modal "Anexar documento assinado", um por página (vem no shell V3.2). Com `data-anexar-opcoes` (JSON com nome, url e atual de cada documento), o modal mostra um seletor para escolher em qual documento anexar; opção sem url (PDF ainda não gerado) vem apagada. Qualquer link para `viagens_oficios:assinatura_artefato` que leve `data-anexar-assinado` abre este modal em vez de ir à página: o formulário recebe o endereço do link, o nome do documento (`data-anexar-nome`) e, se já houver versão assinada (`data-anexar-atual="1"`), a opção de remover. O envio é um POST comum; a view volta para a página de onde se abriu (`next`). Sem JavaScript o link continua levando à página própria. {% endcomment %}
